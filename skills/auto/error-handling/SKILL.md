---
name: error-handling
description: Use this skill to manage and troubleshoot errors during execution.
---
1. Capture error messages and stack traces when failures occur.
2. Identify the type of error (e.g., FileNotFoundError, ValueError) and its context.
3. Check for missing files or incorrect paths in the error messages.
4. Review the code or commands that led to the error for potential issues.
5. Implement logging to capture relevant information for debugging.
6. Test changes incrementally to isolate and resolve issues effectively.
